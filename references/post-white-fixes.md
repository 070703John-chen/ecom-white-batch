# 白底之后：擦丝印、贴字、修图配方

白底链只管**底子**。模型出的字必须自己擦、自己画。

## 擦假丝印（模型编的文字）

按缺陷类型分三种做法，**用错工具会把商品一起弄坏**：

| 缺陷 | 做法 | 禁忌 |
|---|---|---|
| 灯带表面的丝印字 | **左右边界列线性插值**（沿灯带横向取左右边界像素插值填充） | **不要用 inpaint** —— 会留下 X 形亮斑 |
| 盒面/包装上的假 logo | 归一化矩形 inpaint（OCR 抓不到也要擦） | — |
| 手机屏/UI 上的假小字 | **一律自己 PIL 画** | 不要指望模型画可信小字 |

**擦小件的 inpaint 安全阈值是 `gray < 190`**；阈值 225 会把白色主体自身的层次一起洗白。

## 自动擦字的判死结论

灯带类**自动擦字已判定不成立**（rows / median / letters 三种方法 0/3 有效）。
别再调参数 —— 假丝印只有两条路：

1. **生成时就不画**（提示词层去印字诱因 + 描述层去"文字类名词"）
2. **挑底图**（从候选里选一张本来就没丝印的）

自动擦只作为兜底，且**必须与原图比分**才能当交付图：擦丝印会把 LED 封装边缘一起糊掉，
实测有从 90.8 分掉到 68.4 分的案例。

## 自己画真文案

模型画不出可信小字 ⇒ **一律自己 PIL 画**，文字逐字正确才算过。

气泡宽度要扣头像半径：`w_ratio` 0.16 不够，**0.225 够**。

## 主体固有色

商品的本体颜色（不是包装色、背景色、文字色、界面色、发光色、道具色）**从来没自动进过提示词**，
需要显式写进身份锁：

```
商品本体颜色（必须与竞品一致，不得改色）: 深橄榄灰
```

但**主体固有色不是靠提示词能锁住的字段**：要么喂竞品原图（整图当参考），
要么生图后换色/局部重绘。两条路都试过，喂原图更省事。

## 白底 + 白主体（最难的组合）

白色/自发光主体 + 白底，RMBG 的 alpha 只有 **0.008~0.13**，抠图模型基本失效。

解法：**阈值 + 轮廓填充 + 羽化**

```python
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
thr = np.median(gray) - 5          # 背景中位数自适应
mask = (gray < thr).astype(np.uint8)
# 轮廓填充 + 羽化
```

背景中位数要**自适应**：模型常给浅灰底，写死 255 会把主体一起抠掉。

## 多件阵列：件数交给程序，不交给提示词

实测：多件阵列的件数在 1/3/4/6/8 之间乱跳；写排布更糟；不写件数变成"一支多管灯"。

⇒ **模型只画一支，件数和排列由脚本按竞品构图排。**

排版时的两个坑：

- **端头语义无法自动判定**（双管并排时端头宽度几乎相同，6 种判据全废）⇒ 端头方向由人工给一次方向向量。
- `cv2.getRotationMatrix2D` 的**正角 = 屏幕逆时针**，与数学角差符号相反：
  `rot = -(a_cmp - a_our)`。

## 交付口径

程序化排版的产物是"**单件来自模型 + 阵列来自脚本**"的混合产物，
台账/交付说明里**必须如实写明**，不得冒充纯链产出。
